# Banibrata's Portfolio 🚀

Welcome to the source code of my personal portfolio website! This project showcases my skills, experience, and the projects I have built as a Full-Stack Developer.

## 🌟 Features

- **Interactive Hero Section:** Features a stunning scroll-based canvas animation using an image sequence (`video_frames_24fps`).
- **Responsive Design:** Fully responsive and optimized for both desktop and mobile devices.
- **Modern UI/UX:** Clean, elegant, and modern interface with smooth scrolling and animations.
- **Projects Showcase:** Highlights my best work with direct links to live demos and GitHub repositories.
- **Contact Form:** Easy-to-use mailto contact form to get in touch directly.

## 🛠️ Technologies Used

- **HTML5** for semantics and structure.
- **CSS3** for styling, custom variables, and responsive grids.
- **Vanilla JavaScript (ES6+)** for scroll interactions, canvas drawing, and DOM manipulation.
- **Canvas API** for rendering the scroll-based video frame sequence.
- **Phosphor Icons** for clean and consistent iconography.

## 🚀 Getting Started (Local Development)

To run this project locally, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/banibrataBuilds/Portfolio.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd Portfolio
   ```
3. **Run a local server:**
   You can use any local server like VS Code's Live Server extension, or simply run:
   ```bash
   npx serve .
   ```
4. **Open in browser:**
   Navigate to `http://localhost:3000` (or the port provided by your server).

## ☁️ Deployment (Vercel Ready)

This project is fully flexible and configured to be deployed on **Vercel** with zero configuration required. A `vercel.json` file is included to ensure clean URLs, trailing slash management, and optimal caching for the heavy image frame assets.

### Deploying to Vercel:

1. Push your latest code to GitHub.
2. Go to your [Vercel Dashboard](https://vercel.com/dashboard).
3. Click **Add New... > Project**.
4. Import this GitHub repository.
5. Vercel will automatically detect the static files. Click **Deploy**!
